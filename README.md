# แผนแก้หลังค่อม 12 สัปดาห์

คู่มือแก้ไหล่ห่อ คอยื่น และหลังส่วนบนค่อม (Upper Crossed Syndrome) มีภาพประกอบทุกท่าและแผนฝึกรายสัปดาห์ 12 สัปดาห์

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย หรือเปิดผ่าน GitHub Pages

## เนื้อหา
- Wall test สำหรับเช็กท่าทาง
- กลุ่ม A ยืด (ทุกวัน): Chin tuck, Doorway stretch, Thoracic extension, Upper trap stretch
- กลุ่ม B สร้างกล้ามเนื้อ (3–4 วัน/สัปดาห์): Wall angel, Prone Y-T-W, Band pull-apart, Band row, Face pull
- แผน 3 ระยะ: ปลดล็อก (สัปดาห์ 1–4) → สร้างแรง (5–8) → ทำให้ติดตัว (9–12)
- ช่องติ๊กบันทึกการฝึก (เก็บในเบราว์เซอร์)

> เนื้อหานี้เป็นข้อมูลทั่วไป ไม่ใช่คำแนะนำทางการแพทย์ ถ้ามีอาการชา ปวดร้าวลงแขน หรือปวดมากขึ้น ควรพบนักกายภาพบำบัด
